# Residential Apartments Platform — Frontend by Zere

Vite + React + TypeScript + Tailwind CSS frontend.

## Current state

This is all demo, no data(yet). It uses mock data inside `src/App.tsx`, so FastAPI is not required(yet).
The UI interactions work locally in React. Later, will be added FastAPI.

## Main files

- `src/App.tsx` — React UI, demo data, page interactions
- `src/index.css` — Tailwind setup, fonts, colors and global styles
- `src/main.tsx` — React entry point
- `vite.config.ts` —  Vite configuration
